# 단톡방에서 나만 공지를 못 봤다 · 누가 2층이래?

한국어 학습자를 위한 정보차(information gap) 게임이에요. 팀원 네 명이 각자 다른 단서를 가지고, 귓속말로 정보를 나눠 축제 결승 15분 전에 진짜 장소를 찾아요.

- 게임 (`mid/`): 직접 들은 말과 전해 들은 말 구별하기

## 쓰는 법

1. 선생님이 역할 카드(QR 4장)를 띄우거나 인쇄해요.
2. 학생은 팀마다 카드를 한 장씩 뽑고 QR을 휴대폰으로 찍어요.
3. 내 단서는 나만 봐요. 알게 된 것은 팀원에게 귓속말로 전해요.
4. 엔딩에서 팀 번호를 고르면 나오는 결과 카드를 캡처해서 선생님께 내요.

듣기 단서는 휴대폰의 기본 음성으로 읽어요. 이어폰을 준비해 주세요.
